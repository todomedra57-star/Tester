# Invitation templates

Templates built to the "Anatomy of an invitation" guide: three files each,
written against the view model, plus a preview harness to see them.

| Template | Look |
|---|---|
| `navy-bloom` | Cream paper with a faint palace sketch, navy cards with watercolor blue flowers on the corners, wax-sealed envelope with the couple's photos, sticky names the card slides over, 3D coverflow gallery |
| `nile-royal` | Moonlit celebration beside the Nile: palace arch window with mashrabiya screen, full moon, domes and gardens, the Nile with a moon path, lotus columns, a floating vellum panel with jasmine and olive, Nile-wave dividers. 6 palettes incl. Midnight Nile |
| `porcelain` | Blue-and-white china: a gilded plate turning in 3D, vine pattern, glazed cards with gold and cobalt rims. 5 palettes incl. Midnight china |
| `glass-garden` | Victorian glasshouse at golden hour: frosted-glass cards (backdrop blur), brass frame, ferns and ivy over the edges, reflections under the gallery, floating pollen light |
| `lace` | Bridal lace and pearls on silk: pearl garland, lace doily portrait, satin ribbon, pearl rows and lace trims on every card, script names |
| `desert-bloom` | Arabian desert at sunset: four dunes moving at different speeds (multi-layer parallax), glowing sun, palms and desert roses, sand cards, drifting sand glints |
| `andalus` | Moonlit Andalusian courtyard: horseshoe-arch gate, 3D zellige floor, hanging lanterns that swing with the scroll, turning rosettes, arched ivory cards, gold dust, 3D arcade gallery |
| `deco` | Gatsby Art Deco: onyx and gold, sunburst rays, chamfered foil frames, stepped corners, fans that open on scroll, a playing-card gallery |
| `atelier` | Fashion magazine: marble and ivory, huge outlined names drifting over a sticky cover photo, offset gold lines, numbered photos, black-and-white-to-colour gallery |
| `royal` | Palace ball: burgundy velvet, damask, curtains that part on scroll, gold crest, ribbon banner, gilded oval portraits, wax-sealed cards, 3D framed gallery |
| `midnight` | Minimal dark navy: hairlines, a small crescent, quiet stars |

## How Navy Bloom gets its depth (all CSS, no template JavaScript)

1. **Fixed background layers**: paper grain + palace sketch on `.nb::before/::after`
   with `position: fixed`, so the page scrolls over them.
2. **Floating cards**: navy cards with layered shadows.
3. **Art overlapping edges**: flower image tokens on card corners (`.nb-card::after`)
   and on both sides of the envelope, crossing the card edge.
4. **Sticky names**: `position: sticky` headline; the invitation card (higher
   z-index) slides over it.
5. **Scroll-driven 3D**: `animation-timeline: view()` grows the flowers in and
   turns the gallery into a coverflow (`perspective` + `rotateY`), with a flat
   fallback where unsupported.
6. **Own reveal effect** `fx-rise3d`: cards tip up from a slight 3D angle.

Artwork lives in `preview/library/` (original SVGs generated by
`node tools/make-art.mjs`, `make-art-andalus.mjs`, `make-art-more.mjs`, `make-art-luxe.mjs` and `make-art-nile.mjs`). On the platform these become library images picked
through image tokens (`paperTexture`, `backdropArt`, `cornerArt`, `sprayArt`,
`sealArt`, `dividerArt`). For production, painted watercolor PNG/WebP art will
look richer still.

## Couple options

Every template now offers, on top of its own choices:

| Choice | Options |
|---|---|
| Palettes | 5 to 7 per template, incl. gold, silver and rose-gold metals |
| Photo frame | the template's own frames + heart, hexagon, polaroid |
| Gallery | the template's 3D mode(s) + strip, mosaic grid, scattered polaroids |
| Date | badge, gold ribbon, double frame, between hairlines, month calendar |
| Ornament | rich, refined (quiet), opulent (gold glow) |
| Cover layout | 3 layouts in Porcelain, Glass Garden, Lace and Desert Bloom |
| Photo tone | natural, golden, palette-toned, black and white (any photo matches the design) |
| Entrance | cinematic build-up of the cover after opening, gentle, or none; sections reveal title, then a drawn gold line, then content |
| Metal | palette gold, champagne, rose gold, silver, iridescent pearl (derived from the accent token with relative colours) |
| Font pairing | as designed, classic, modern, script, geometric (extra font tokens) |

Photo frames also get a **shimmer**: light runs around the gilded frames as
you scroll (a registered `@property` angle on a scroll timeline).

`python3 tools/add-options.py` adds these to every template (manifest options,
palettes and an "options pack" at the end of each style.css). It is safe to
re-run. `tools/build-luxe-templates.py` regenerates the four newest templates
and runs it automatically.

Their art is used as **CSS masks filled with palette tokens**, so a single
drawing works in every colourway. On the platform, library images used as
masks must be served with CORS headers (`Access-Control-Allow-Origin`), or
browsers will not draw them.

## Midnight

```
templates/midnight/
  manifest.json   texts (ar/en), tokens, palettes, variants, default animation
  template.html   Handlebars sections: cover, countdown, story, gallery, events, wishes, footer
  style.css       token variables only, logical properties, mobile first, max 520px
preview/          stand-in for the platform (helpers, opening, reveal, wishes box)
index.html        preview page
```

## Preview

Serve the folder over http (fetch doesn't work from `file://`):

```
npx serve .        # or: python3 -m http.server
```

Use the controls to switch test case (Arabic demo, English, smallest, longest),
palette, date style, countdown style, photo frame, opening, stars and motion.

## The design

- **Palettes:** Navy & ice (default), Navy & gold, Indigo & pearl.
- **Signature:** hairline frame inset on the cover, a thread dropping to a small
  crescent, a diamond on each divider, and offset hairline photo frames.
- **Variants:** `dateStyle` line | badge | calendar · `countdownStyle` ring | plain ·
  `photoFrame` offset | arch | circle.
- **Own effect:** `ambient-stars`, quiet twinkling stars for night weddings.

## Making another template like this

Copy `templates/midnight/`, rename the `key`, and change mainly `style.css` and
the palettes. Keep the rules from the guide: no `<script>`, no fixed words in
the HTML (`{{text "key"}}`), no `{{{ }}}`, colors and fonts only via `--c-*` /
`--font-*`, own classes prefixed `.fx-` / `.intro-` / `.ambient-`.
To preview it, add it to `TEMPLATES` at the top of `preview/preview.js`.

## Quality checks

```
node tools/check-templates.mjs          # rule checker (exit 1 on errors)
python3 -m http.server 8765 &           # then:
node tools/qa-screenshots.js            # visual QA → qa/report.html
```

- **Rule checker** (no dependencies): manifest (texts in both languages, required
  tokens, valid defaults and palettes, known effects), template.html (no script,
  no on…=, no {{{ }}}, no fixed words, sections in order, one wishes box, one
  parallax layer, every {{text}} key and variant option defined) and style.css
  (balanced braces, allowed at-rules only, no url(), no raw colours, font tokens
  only, logical properties, reduced motion, effect and keyframe naming).
- **Visual QA** renders every template in the four test cases (Arabic, English,
  smallest, longest) plus a cover per palette, and flags sideways scrolling,
  text off screen, broken images, text left invisible and page errors.
  Set `QA_HANDLEBARS=/path/handlebars.min.js` if the CDN is unreachable.
